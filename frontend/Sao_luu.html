Sao lưu và phục hồi dữ liệu

Sao lưu là gì?

Lưu một bản dữ liệu SQL Server tại thời điểm sao lưu vào file .bak, để có thể khôi phục khi máy hoặc dữ liệu gặp sự cố.

Quản trị SQL Server chạy tác vụ sao lưu trên máy chủ, kiểm tra file và cất thêm một bản ở nơi lưu trữ riêng.

Phục hồi là gì?

Tạo lại cơ sở dữ liệu từ một bản .bak đã kiểm tra. Dữ liệu sau thời điểm bản sao lưu không tự có trong bản phục hồi.

Thử phục hồi sang database mới trước; kiểm tra tính toàn vẹn và đối chiếu dữ liệu trước khi sử dụng.

Ai thực hiện?

Quản trị SQL Server thực hiện trên máy chủ. Menu này là hướng dẫn; bấm vào không tự sao lưu hoặc phục hồi. Tài khoản chạy web không được cấp quyền BACKUP/RESTORE.

Không phục hồi đè database đang vận hành. Việc thay database thật cần kế hoạch và phê duyệt riêng.

Hướng dẫn kỹ thuật cho quản trị
  1. Sao lưu: chọn file .bak mới; dùng scripts/backup-database.sql với biến BackupFile. SQL Server phải có quyền ghi thư mục đích.
  2. Script dùng COPY_ONLY, CHECKSUM và VERIFYONLY; không ghi đè bản sao lưu.
  3. Đọc HEADERONLY và FILELISTONLY, sau đó dùng scripts/restore-test-database.sql để phục hồi thử vào database mới chưa tồn tại.
  4. Chạy CHECKDB, đối chiếu dữ liệu và lưu kết quả kiểm tra.
